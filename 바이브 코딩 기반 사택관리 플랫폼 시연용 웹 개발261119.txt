바이브 코딩 기반 사택관리 플랫폼 시연용 웹 개발


프로젝트 상세
업무 내용
[프로젝트 개요]
- 공공기관·대기업 지방 발령 직원의 사택을 발령부터 계약, 입주, 매월 비용, 반납까지 한곳에서 관리하는 플랫폼의 시연용 웹 프로토타입을 구축하고자 합니다.
- 실제 백엔드 서버 구축이나 외부 유료 API 실연동은 제외하며, 오는 11월 28일까지 개발을 완료하여 12월 1일에 납품해야 하는 일정이 명확한 시연용 프로젝트입니다.
- 기존에 AI 제작 도구로 만들어 둔 시제품 작업물과 상세 기획서를 바탕으로, 개발자분께서 가장 능숙하게 다루시는 바이브 코딩 툴(Claude Code, Cursor, Codex 등)을 활용해 투박하지 않고 깔끔한 시연용 웹 화면을 빠르게 완성해 주실 분을 찾습니다.
 
[클라이언트 소개]
- 공공기관 및 대기업 대상 사택 위탁 운영·관리 플랫폼을 준비 중인 팀입니다.
- 프로젝트 의사결정 구조: 기획서를 직접 작성한 담당자가 단독으로 소통하며, 11월 20일에 신속히 미팅을 진행한 후 바로 파트너를 확정할 예정입니다.
- 개발 지식: AI 도구를 활용해 직접 1차 시제품을 제작해 보았으며, 9개 역할별 권한, 18개 데이터 구조, 화면별 요구사항이 정리된 완성도 높은 기획서와 기존 작업 내역을 보유하고 있습니다.
 
[왜 이 프로젝트를 하는가]
- 지금 상황: 기존 AI 제작 도구에 비용과 시간을 들여 1차 시제품을 만들었으나, 새 파일 생성 권한이 막혀 일부 화면이 누락되고 운영자 어드민 13개 메뉴가 실제 화면이 아닌 안내 문구로만 들어가는 등 직접 수정하는 데 한계가 있었습니다.
- 끝나면 이렇게 되기를 바랍니다: 투박해 보이지 않는 깔끔한 UI로 기획서상의 역할별 업무 화면과 운영자 어드민 화면들이 빠짐없이 연결되어, 웹 링크 하나로 완벽한 시연이 가능해지기를 바랍니다.
- 다만 이런 점이 우려됩니다: 11월 28일까지 완료되어야 하는 촉박한 일정이므로 속도감 있는 작업이 필수적이며, 시연 시 역할을 바꿔가며 클릭할 때 샘플 데이터와 승인·잠금 상태가 앞뒤가 맞게 연결되어야 합니다.
 
[필수 과업 범위와 결과물]
1. 수행 범위
- SW 개발: 기획서 및 기존 작업물 기반 시연용 반응형 웹 프론트엔드 화면 구축 및 시연용 상태·샘플 데이터(Mock Data) 연동 (※ 실제 백엔드 서버·DB 구축 제외)
- 외부 연동: 실연동 없음 (등기부등본 열람, 세금계산서 요청, 대금 이체, 알림톡 발송 등은 시연용 화면 표시 및 상태 변경으로만 구현)
- 인프라 구축·배포: 외부에서 링크로 즉시 접속하여 시연할 수 있도록 웹 호스팅 배포 및 없는 주소(404) 안내 설정
 
2. 상세 기능 요구 사항
2-1. 공개 영역 및 역할 전환형 시연 환경
- 공개 페이지 구성: 정식 메인 화면(핵심 메시지, 3대 원칙, 신뢰 지표), 서비스 소개(기관용·직원용 분리), 도입 문의 폼, 개인정보 처리 안내 구현
- 역할별 시연 로그인 및 접근 제어: 9개 역할(발령자, 사택담당자, 인사담당자, 결재권자, 공인중개사, 관리사무소, 임대인, 사택온 운영자, 감사자)을 선택·전환하며 시연할 수 있는 구조 및 타 역할 주소 접근 시 권한 안내 표시
2-2. 9개 역할별 업무 화면 및 핵심 시연 규칙 반영
- 발령 및 물건 확보 화면: 인사담당자 발령 등록·목록, 사택담당자 공실 확인·주거 요청서·후보 판별, 공인중개사 후보 물건 제출 화면 구현
- 입주 신청 및 초과 결재 연동: 발령자 내 사택·후보 상세·입주 신청 화면 구현, 월세가 직급 한도 이내면 자동 승인되고 한도 초과 시 결재권자의 초과 결재함 승인 전까지 계약 기록이 잠기는 시연 흐름 구현
- 매월 비용·수리·반납 화면: 발령자 선납 후 환급 및 입주 준비·매월 비용 통합 화면, 사택담당자 계약 기록 및 대금 대사 화면, 관리사무소 납부현황·시설 수리요청 화면, 임대인 화면, 반납·재고 목록 화면 구현
- 민감 정보 마스킹 표시: 역할에 따라 등기부등본 원본(담당자·중개사)과 개인정보를 가린 요약본(발령자)을 구분 표시하고, 임대인 계좌번호 가운데 자리 가림 표시 적용
2-3. 사택온 운영자 관리자 페이지 (13개 메뉴 화면화)
- 관리자 레이아웃 및 고객사 필터: 좌측 고정 메뉴(모바일은 상단 접이식), 우측 본문, 상단 고객사 선택 필터 및 표 엑셀 다운로드 버튼 UI 구성
- 13개 메뉴 화면 구축: 대시보드, 고객사 관리(직급 한도표·수수료 규칙), 계정·권한, 발령·요청 현황(부임일 14일 이내 지연 위험 표시), 후보 물건 심사, 계약 관리(6가지 지급 요건 체크), 파트너·임대인, 청구·입금, 지급 배치·대사, 세금계산서, 실비 청구 심사(중복 의심 표시), 통지 내역, 기록·설정 화면 구현
2-4. 정확성 3대 원칙 목표 화면 (시연용 UI)
- 기준 내재화 및 규정 보존 화면: 기관별 결재라인·지원기준 설정 UI, 규정 원본 업로드 및 버전(v1, v2) 개정 전후 비교 화면 구현
- 대사 센터 및 감사 로그 화면: 승인·계약·지급 대조 결과 및 불일치 조치 추적 화면, 분기 리포트 및 기간·사용자별 감사 로그 조회 화면 구현
 
3. 결과물
- 시연용 웹 프로토타입 프론트엔드 소스코드 일체
- 외부 시연이 가능한 웹 배포 링크(URL)
 
[클라이언트 준비 사항]
- 준비된 것: 사택온 플랫폼 상세 기획서·설계도(화면 목록, 9개 역할 정의, 18개 데이터 구조, 핵심 업무 규칙 총정리 문서), 기존 AI 도구 작업 기록 및 입력 문서(md/docx), 대금지급 구조도, 등기부 연동 설계서, 기존 시제품 링크
- 준비 중인 것: 미팅 시 전달할 세부 시연 흐름 설명 자료
- 이 프로젝트 담당: 기획서 작성자가 직접 미팅 및 빠른 피드백을 전담합니다.
